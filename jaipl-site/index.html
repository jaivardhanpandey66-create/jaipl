A small language for
building things.

Plain text files. No build step. No toolchain to configure before your first program runs. Write .jai in any editor and run it with one command. 

class Dog {
    let name
    func new(name) { self.name = name }
    func speak() { return self.name + " says woof" }
}

print(new Dog("Rex").speak())
$ jaipl run dog.jai Rex says woof
Install Packages Read the guide

Packages

Install a library from the terminal, then use it by name.

Install

jai install mathx

Installed into ~/.jaipl/packages. Add --upgrade to update, jai list to see what you have.

Use

import mathx print(mathx.mean([1, 2, 3]))

A package is a folder of .jai files with a jaipl.json manifest, so you can also install straight from a folder.

Publish

jai publish

Uploads the package to the registry. The registry is self-hosted and standard-library only — tools/registry_server.py.

Install

Linux & macOS

One command. No sudo, nothing outside your home directory.

curl -fsSL https://jaivardhanpandey66-create.github.io/jaipl/install.sh | sh

Puts jaipl in ~/.local/bin. Add --with-associate to register .jai files with your desktop.

Windows

Run it with Python 3.11 or newer, the same way as everywhere else. There is no bundled installer to download yet.

python -m arcide.jaipl.cli run program.jai

A single-file executable is produced by packaging/windows/build-installer.sh on a machine with Inno Setup. Until one is published here, use the command above.

Any editor

There is a VS Code extension on the Marketplace.

code --install-extension jaipl.jaipl

Other editors: point your run command at jaipl run <file>.

From a checkout

git clone https://github.com/jaivardhanpandey66-create/jaipl cd jaipl && ./install.sh --local .

What it looks like

Classes that just work

Fields, methods, one optional constructor called new, and extends for inheritance. Overridden methods dispatch the way you would hope, with nothing to configure.

C++ when you want it

import gpp compiles and runs real C++ from inside a jaipl program and hands the output back. Results are cached by source hash.

Errors that point somewhere

Syntax errors report a line and column and draw a caret under the problem. An accidental infinite loop stops with a message instead of hanging your editor.

In your editor

Highlighting, snippets, F5 to run, Ctrl+Shift+B to check, and errors as red squiggles.

  • Syntax highlighting for every token class the language has
  • Snippets for classes, constructors, loops and maps
  • Problems parsed from the CLI, never re-implemented in the extension
  • jaipl fmt rewrites the buffer, and refuses to if it would change what the program means
